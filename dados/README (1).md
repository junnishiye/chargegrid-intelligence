# Electric Vehicle Charging Patterns Analysis

Projeto desenvolvido para o Challenge Sprint 1 – 1º Semestre, com foco em análise estatística e manipulação de dados utilizando Python.

O trabalho utiliza uma base de dados real sobre padrões de recarga de veículos elétricos para gerar tabelas de distribuição de frequência, identificar padrões de comportamento e extrair insights relevantes para tomada de decisão empresarial.

---

# Objetivo do Projeto

O principal objetivo deste projeto é aplicar conceitos de:

- Estatística Descritiva
- Análise Exploratória de Dados
- Distribuição de Frequência
- Manipulação de Dados com Python
- Interpretação de Insights

A partir disso, o projeto busca compreender os padrões de utilização de estações de recarga de veículos elétricos.

---

# Base de Dados

A base de dados utilizada foi retirada do Kaggle:

https://www.kaggle.com/datasets/valakhorasani/electric-vehicle-charging-patterns/data

## Dados presentes na base

A base contém informações relacionadas a:

- Tempo de recarga
- Custo da recarga
- Tipo de carregador
- Consumo energético
- Padrões de utilização
- Informações quantitativas e qualitativas
